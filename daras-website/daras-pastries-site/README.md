# Dara’s Pastries and Treats website

A lightweight, responsive static website built with HTML, CSS and vanilla JavaScript. Product imagery was cropped from the flyer supplied for this project.

## Files
- `index.html` — page content
- `style.css` — responsive styling
- `script.js` — mobile navigation, menu filters, and WhatsApp enquiry buttons
- `assets/` — flyer and product crops

## Publish with GitHub + Netlify
1. Create a GitHub repository, for example `daras-pastries-and-treats`.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Sign in to Netlify and choose **Add new site → Import an existing project**.
4. Connect GitHub and select the repository.
5. For this plain static site, leave the build command empty and set the publish directory to `.` (the repository root).
6. Deploy. Netlify will provide a live `*.netlify.app` URL.
7. Test the live URL and send it to Dara for approval before sharing publicly.

## Notes
- No framework, build step, database, or API key is required.
- Google Fonts are loaded from the web; system fallbacks are included.
- A custom domain is optional and may cost money.
